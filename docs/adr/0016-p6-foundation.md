## Admission and leagues (00c)

Optional experimental.mechanics: unique nonempty canonical known IDs; omitted=standard.
Registry permissions cannot enable unimplemented variants. Exhaustive resolved closure
includes dormant stages/reactions/status transforms/grants/pulses. Common prepare/job/retry/
league policy rejects before reservations with code/mechanic/revision; retain version gates.
Q-1 concepts experimental; incomplete P6 requires opt-in. Experimental leagues have separate
IDs/ranks/scores, class checked against pinned rules/catalog, Pages label 実験; manual only.
Old class omission means standard only without permissions. Saved reads engine-free.

## Interference (00b)

Domain interference.json covers every ordered/self pair, no implicit independence/symmetry.
Defined cells require rule/summary+independent expected fixture; independent requires reason;
unresolved requires diagnostic regression; rejected requires admission fixture. Coverage binds
executed receipts; baseline fixes484 old outcomes/hashes. Missing-cell/fixture/variant negative
controls required. No undefined accepted standard P6 pair; no ID/order winners. Existing
unresolved semantics stay. Full contract specifies rejected conditional closure handling.

## Unresolved context (00b)

Optional interferenceDiagnostics=v1 adds attempted step/point/wave/actors/causes/revisions/rule;
retain old ruleId/revisions/reason and omitted behavior. Capture before rollback, no dangling
IDs; null wave only outside waves. Caps16entries,2actors/32causes/64refs per entry,32KiB,
reason<=500, existing record limits. Overflow truncated(observed/limit/cause), not partial
context. Roll back costs/RNG/IDs/hits/queues/events/display. Reaction64/transaction,1024/match,
depth8. Worker/SQLite/ReplayState validate bounds/references engine-free.

## Official milestones (00c)

[ADR0015](0015-league.md) amendment for configured official standard scheduling only.

reuse. Validate saved hashes/refs/cross-links before eligibility/slots/reservations.

rules-milestone-required/engine-milestone-required. Includes partial publications; source SHA
alone is not input change. Same definition/identity keeps retry policy, new supported definition
estimates. Only initial pointer404 means unpublished; other corruption/missing/network/auth/
budget failures stay errors. Holds make no writes/reservations. Manual publish rejects old
rules/identity-only change; recovery validates original artifacts without old execution.
